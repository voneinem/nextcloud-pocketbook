# Tasks: Trash and File Versions

**Input**: Design documents from `/specs/006-trash-and-versions/`

**Prerequisites**: [plan.md](plan.md), [spec.md](spec.md), [research.md](research.md), [data-model.md](data-model.md),
[contracts/trash-requests.md](contracts/trash-requests.md), [contracts/core-interfaces.md](contracts/core-interfaces.md),
[contracts/bridge-qml.md](contracts/bridge-qml.md), [quickstart.md](quickstart.md)

**Tests**: REQUIRED. The constitution makes Test-First non-negotiable (Principle I): every implementation task is preceded by test tasks, and
each story has a "red" task that records the new tests failing for the right reason before any implementation task of that story starts. The
server side is the in-process fake Nextcloud; what only a real server or the reader can show is a labelled check (LV-T1..LV-T10, DT-T1..DT-T4,
unverified until run, Principle IX).

**Organization**: Tasks are grouped by user story (US1-US5 of the spec). **Phase order differs from story numbers on purpose** (plan, delivery
order): US5 (what the server offers) comes first because every screen needs it; then US1 (see the trash), US2 (restore), US3 (versions) and
US4 (delete for good). **US4 depends on the trash-screen exception of constitution 1.3.0, which the owner approved and which is in force since 2026-10-24**
(plan, owner point 1); Phases 1 to 6 and 8 are complete without it.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependency on an unfinished task)
- **[Story]**: US1-US5, only in the user-story phases
- Paths are relative to the repository root. `core/include/pbc/X.h` and `core/src/X.cpp` come as a pair; a new `core/src/*.cpp` is added to
  `PBC_CORE_SOURCES` in `core/CMakeLists.txt` in the same task; a new bridge adds its source, header and moc header to the three lists in
  `bridge/CMakeLists.txt`; a new bridge test is added to both `foreach` lists in `tests/CMakeLists.txt`; a new walk to the `ui_walk` list in
  `app/CMakeLists.txt`. `tests/unit/test_*.cpp` and `tests/integration/test_*.cpp` are picked up by the glob.
- Every task that touches a user-visible text also adds the German entry to `qml/strings_de.tsv` (`python3 scripts/extract-strings.py --check`
  must stay green).
- FR-/SC- numbers refer to [spec.md](spec.md); R- numbers to [research.md](research.md); T1..T8 to [contracts/trash-requests.md](contracts/trash-requests.md).
- No task adds a TLS bypass, a timer, polling, a retry, a queue item, a request at start, a log field with a name, location, trash name or
  version id, a `PUT`/`MKCOL`/`COPY` for the trash, a request without its condition (R-5 to R-9), a `DELETE` of the trash collection, or a call
  of `delete_item` outside `TrashBridge` (rules N1-N12 enforce this mechanically once N11 and N12 exist).
- No task edits the constitution: amendment 1.3.0 (2026-10-24: the trash-screen exception and the clause for writes without an ETag) is in force.
